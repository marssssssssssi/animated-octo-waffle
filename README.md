# animated-octo-waffle
# Блок-схема программы мониторинга пиковой нагрузки портала

## Описание программы
Программа суммирует N интервалов времени (10 ≤ N ≤ 30) и вычисляет общее время работы портала.

## Диаграмма алгоритма

```mermaid
flowchart TD
    Start([Начало]) --> A[Вывод заголовка]
    A --> B[Ввод N 10-30]
    
    B --> C{10 ≤ N ≤ 30?}
    C -->|Нет| D[Ошибка: неверный N]
    D --> End1([Завершение])
    
    C -->|Да| E[Выделение памяти]
    
    E --> F{Память выделена?}
    F -->|Нет| G[Ошибка памяти]
    G --> End2([Завершение])
    
    F -->|Да| H[Ввод интервалов]
    
    subgraph H[Функция inputIntervals]
        H1[Заголовок ввода] --> H2[Цикл i=0..N-1]
        H2 --> H3[Ввод часов 0-23]
        H3 --> H4[Ввод минут 0-59]
        H4 --> H5[Ввод секунд 0-59]
        H5 --> H6[i++]
        H6 --> H7{i < N?}
        H7 -->|Да| H3
        H7 -->|Нет| H8[Конец функции]
    end
    
    H --> I[Вывод всех интервалов]
    I --> J[Суммирование времени]
    
    subgraph J[Функция sumIntervals]
        J1[totalSeconds = 0] --> J2[Цикл по интервалам]
        J2 --> J3[Конвертация в секунды]
        J3 --> J4[Добавить к totalSeconds]
        J4 --> J5[Следующий элемент]
        J5 --> J6{Все обработано?}
        J6 -->|Нет| J3
        J6 -->|Да| J7[Нормализация времени]
        J7 --> J8[Возврат результата]
    end
    
    J --> K[Вывод результата]
    K --> L[Освобождение памяти]
    L --> End3([Конец программы])
```
